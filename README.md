# Tennis Plaza — Join The Thrill. Train Like A Pro.

High-craft athletic modern landing page for Tennis Plaza. Built with HTML5, Tailwind CSS, GSAP ScrollTrigger, and Alpine.js.

## Features
- Athletic Display Typography with signature alternating italic & heavy roman fonts (Plus Jakarta Sans).
- Faceted badge clip-paths and dark court aesthetic with lime neon highlights.
- Interactive Coaching & Court Booking Modal with responsive step flows.
- Giant watermark footer design and smooth micro-interactions.
- Ultra lightweight runtime (~10kB Alpine.js, CDN Tailwind, zero heavy framework overhead).

## Tech Stack
- HTML5 & CSS3
- Styling: [Tailwind CSS](https://tailwindcss.com/)
- Interactivity: [Alpine.js](https://alpinejs.dev/)
- Animations: [GSAP](https://greensock.com/gsap/) + ScrollTrigger
